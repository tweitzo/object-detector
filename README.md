# AI Image Object Detection

Веб-приложение для обнаружения объектов на загружаемых изображениях с помощью искусственного интеллекта.

Пользователь загружает изображение через интерфейс Streamlit. Модель **DETR ResNet-50** из Hugging Face находит объекты, определяет их классы и координаты, после чего приложение показывает изображение с рамками, уверенность модели и таблицу результатов.

## Возможности

- Загрузка изображений в форматах JPG, JPEG, PNG и WEBP.
- Распознавание объектов с помощью предобученной модели Hugging Face.
- Настройка порога уверенности.
- Отображение рамок и названий обнаруженных объектов.
- Подсчёт общего количества объектов и количества объектов каждого класса.
- Таблица с уверенностью и координатами обнаруженных объектов.
- Скачивание обработанного изображения в формате PNG.
- Автоматическое использование CUDA, если доступна совместимая видеокарта; иначе используется CPU.

## Модель

Используется [`facebook/detr-resnet-50`](https://huggingface.co/facebook/detr-resnet-50).

Это модель обнаружения объектов на базе Detection Transformer (DETR) с ResNet-50. Она предварительно обучена на COCO 2017. Модель распознаёт категории объектов из набора COCO, а не любые возможные предметы.

При первом запуске веса модели автоматически загружаются с Hugging Face. Для этого требуется подключение к интернету. Токен Hugging Face для публичной модели не требуется.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/YOUR_USERNAME/ai-image-object-detection.git
cd ai-image-object-detection
```

### 2. Создание виртуального окружения

Windows:

```bash
python -m venv venv
venv\Scripts\activate
```

Linux / macOS:

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Примечание: PyTorch — крупная зависимость. Если нужна поддержка NVIDIA CUDA, установите подходящую сборку PyTorch по инструкции на [официальном сайте](https://pytorch.org/get-started/locally/), затем установите остальные зависимости из `requirements.txt`.

### 4. Запуск приложения

```bash
streamlit run app.py
```

После запуска Streamlit откроет приложение в браузере. Если браузер не открылся автоматически, перейдите по адресу, который появится в терминале (обычно `http://localhost:8501`).

## Использование

1. Откройте приложение.
2. Загрузите изображение.
3. Выберите порог уверенности в боковой панели.
4. Нажмите **«Распознать объекты»**.
5. Изучите изображение с рамками и таблицу найденных объектов.
6. При необходимости скачайте результат.

## Ограничения

- Качество распознавания зависит от освещения, размера объектов, ракурса и качества изображения.
- Модель обучена на категориях COCO и может не распознать редкие или специализированные объекты.
- Низкий порог уверенности может увеличить количество ошибочных обнаружений.
- На CPU обработка может занимать больше времени, чем на GPU.
- Первичная загрузка весов модели требует интернета.
